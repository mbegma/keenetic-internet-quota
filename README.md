# Keenetic Internet Quota — V1.2

Скрипты для KeeneticOS / Entware, которые ограничивают ежедневное активное время использования интернета одним устройством. Активность определяется по приросту RX/TX-счётчиков трафика.

## Состав

- `opt/bin/internet_quota.sh` — мониторинг трафика и учёт активного времени.
- `opt/etc/init.d/S99internet_quota` — управление сервисом квоты (`start`, `stop`, `restart`, `status`, `config`, `reset`).
- `opt/etc/internet_quota/internet_quota.conf` — MAC устройства, интервал проверки, порог активности и дневной лимит.
- `opt/etc/init.d/S98internet_web` — управление веб-интерфейсом.
- `opt/etc/internet_web/` — настройки веб-сервера `lighttpd`.
- `opt/share/internet_web/` — HTML и CGI веб-интерфейса (используют относительные пути для работы в подкаталоге `/quota/`).

## Настройки по умолчанию

В `opt/etc/internet_quota/internet_quota.conf` сейчас указаны:

- MAC устройства: `b2:a2:38:9c:f2:97`
- Интервал измерения: `3` секунды
- Порог активности: `10000` байт за интервал
- Дневной лимит: `7200` секунд (2 часа)

Перед установкой на другой роутер или для другого устройства проверь эти параметры.

## Важные замечания

- Файл `internet_quota.state` намеренно не включён: он содержит изменяемое состояние конкретного роутера и не должен сбрасываться при обновлении кода.
- Runtime-файлы PID, журналы и временные файлы исключены через `.gitignore`.
- Веб-интерфейс настроен на привязку к `192.168.1.1:8080/quota/` (через общий веб-хаб `lighttpd` с корневым каталогом `/opt/share/www`). Перед использованием проверь сетевую доступность и безопасность доступа к CGI-командам.

## Установка

Сохраняй структуру каталогов `opt/...` при копировании файлов в Entware на роутере. Перед заменой работающих файлов сделай резервную копию текущих версий.

## История версий

- **V1** — базовая версия мониторинга трафика, учёта дневной квоты и веб-интерфейса.
- **V1.1** — исправлена обработка флага `BLOCKED` при сбросе квоты (`reset` при `BLOCKED=1` снимает политику `NoInternet`).
- **V1.2** — веб-интерфейс переведён на относительные пути для размещения по адресу `/quota/` на общем локальном веб-сервере `lighttpd`; подтверждено срабатывание автоматической блокировки политикой `NoInternet` при исчерпании квоты.
